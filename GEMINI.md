# GEMINI.md (Antigravity / Gemini)

Read `AGENTS.md` in the repository root first. It is the single source of truth and applies to you in full. Then follow the read order in its section 3.

Notes for Antigravity:

- Run in your own git worktree and branch (see `docs/BRANCHING.md`). Do not share a working directory with another agent.
- Keep terminal commands inside the worktree. Ask your human before running anything destructive or installing system-wide packages.
- Save plans and summaries into the repo (your track's handoff file), not only in Antigravity artifacts, so other agents and teammates can read them.
- If your Antigravity version does not load `AGENTS.md` automatically, paste the start-of-session prompt from `docs/AGENT_PROMPTS.md`.
