# Claude Code notes

Everything important is in `AGENTS.md` (imported above). Extra notes for Claude Code:

- Work inside your own git worktree (see `docs/BRANCHING.md`), never in another track's directory.
- Use plan mode for anything touching an interface, the export pipeline or more than three files. Show the plan before editing.
- At the end of a session, update your track's file in `docs/handoffs/` using the template in `HANDOFF.md` before you stop.
- Do not edit `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` or `docs/CONTRACTS.md` from a track branch.
